# A-B-testing
You're building a tool to analyze whether a change (like a new website button color, email subject line, or app feature) actually improves user behavior compared to the original version.
Step 1: Understanding A/B Testing
An A/B test splits users into two groups:
- Control Group (A): Sees the original version
- Treatment Group (B): Sees the new version
You measure a metric (conversion rate, click-through rate, etc.) and determine if B is statistically better than A.
